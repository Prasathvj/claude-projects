# Context-driven motion style (owner, 2026-11-24; refs: motion_ref1, motion_ref2_3). OUR colours always.
CORE IDEA: the visual follows the WORDS. Every phrase (often every 2-4 words) triggers an element or effect that
literally shows that phrase, so something meaningful changes every ~0.5-1 s. Nothing decorative or generic.
Examples from the refs (phrase -> element):
- "5 million views" -> dark stats card, number counts up, lands, flashes accent, snaps to "5M" + impact ticks
- "in 35 days" -> flip calendar races DAY 1 -> 35 (pages fly off), then a "35 DAYS" rubber stamp slams on
- "not by an AI video model" -> "NOT AI-GENERATED" headline (NOT in accent), glitchy AI frame gets a big accent X, code frame gets a green check badge
- "made programmatically" -> code editor --(dashed arrow)--> phone screen; "MADE WITH CODE" slams in
- "you type one line" -> chat input; letters type in, the matching keyboard keys light up; cursor clicks a tab with a focus circle
- "the exact system" -> sunburst rays behind the object, corner focus brackets close in, "FOR YOU" price tag swings, "SEALED" tape + padlock drop
- "this market fills up fast" -> seat map filling with accent seats, then "FULL" stamp; "first come" -> ticket machine "No. 2481"
- "word lands a beat before it's said" -> caption timeline with a "-0.15 s" tag
- "scores its own motion" -> score dial "3.8/10" -> "6.2", film strip with frames checked
FRAME LAYOUT (9:16): tiny mono section label top-left ("// 05 · the rules") + live mono counter top-right ("FOLLOWERS 39,532" ticking);
caption at TOP, word by word (next word as a faint ghost), key words in italic serif accent; main element block mid-frame;
HOST at bottom-centre, changing gesture/expression on every line (open hands, shrug, point up, thumbs, cover mouth, laugh).
TRANSITIONS: halftone-dot wipe (dots grow to full black, then shrink to the next scene) between sections; quick black flash; 3D tilt swing-in;
finished element shrinks into a tracker slot. Micro-motion everywhere: impact ticks, small wobble, shadows, focus circles, pages flying.
TEXTURE: paper with fine halftone dots; sticker-style realistic objects with soft shadow; dark UI cards for app screens.
OUR VERSION: cream #F4EDE3 + dots, dark-brown text #2A2018, accent = orange->red gradient (#F87736->#E8402E), white cards, Montserrat (bold sans)
+ an italic serif for accent words; Max as the host (bottom-centre in Shorts). No copying their assets, screens or avatar.
