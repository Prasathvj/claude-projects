**Title:** Deleting a file doesn't delete it #shorts
Alt: Where your deleted files actually go

**Description:**
On a traditional hard drive, deleting a file mostly removes its entry from the drive's index. The data stays on the disk, marked as free space, until new files overwrite it, which is how recovery tools bring files back, and why selling an old hard drive without wiping it is risky. SSDs are different: the computer sends a TRIM command telling the drive which blocks are no longer needed, and the drive clears them in the background, so a deleted file can be gone for good within moments. Back up what matters.
