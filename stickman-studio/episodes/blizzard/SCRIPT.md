## Fact-check notes (read before approving)

Every safety claim below is tied to guidance found on 2026-11-17. I could not open the National Weather
Service page itself, so wording on it is unverified; the claims are consistent across the other sources.

| Claim in the script | Source |
| --- | --- |
| Stay in the car unless help is clearly in sight (about 100 yards) | [Michigan State Police](https://www.michigan.gov/msp/divisions/ohsp/safety-programs/winter-driving/know-how-to-handle-winter-driving-emergencies), state winter-driving sheets, Red Cross |
| Run the engine about 10 minutes each hour, heater on | [Fox Weather, citing NWS experts](https://foxweather.com/weather-news/how-survive-your-car-stuck-during-winter-storm); Red Cross (MN/ND/SD) |
| Keep the tailpipe clear of snow | [Massachusetts state page](https://www.mass.gov/info-details/in-case-you-are-stranded-while-driving-in-the-winter), Michigan State Police |
| Crack a window on the downwind side; carbon monoxide can still build with a clear pipe | [ReadyNH](https://www.readynh.gov/disasters/winter-storms.htm), New Bedford emergency management |
| Bright cloth on the antenna; raise the hood once snow stops | Multiple state and local pages |
| Keep covered; small movements keep circulation going | Red Cross, state sheets |
| Hypothermia signs: uncontrollable shivering, slow or slurred speech, memory lapses, stumbling, drowsiness | State health pages summarising Red Cross guidance |
| Carbon monoxide has no smell and no colour | General public-health fact |
| Winter kit list (blankets, flashlight, charger, water, snacks, shovel) | Standard kit lists; low risk, still worth a glance |

Left out on purpose because I could not confirm them: "do not eat snow" and any claim about overexertion.
